## Objective

Compare every stored account across per-model quota buckets with `usage --all`, and make `switch --live` auto-switch see model-level exhaustion even when the shared 5H/weekly summary is healthy.

## Context

The summary-based auto-switch from the previous slice cannot see Gemini-only exhaustion. `retrieveUserQuota` already provides model buckets, but the live path only fetched the summary and `usage` only handled one account. This slice joins those paths with a full fetch and a shared TTL cache.

## Scope

### In scope

- `usage.Client.FetchFull` returning plan, shared summary, per-model buckets, and a non-fatal partial error.
- `usage.FullCache` with the same TTL as the live interval.
- `usage --all` table and JSON comparison: account, plan, 5H, weekly, lowest model percent, model, reset, and per-row error.
- Live rows store fresh model detail; auto-switch considers a 0% model bucket as exhaustion and skips stale detail.
- Tests for full fetch, partial summary failure, full-cache stale fallback, `usage --all` output/JSON/errors, and detail-aware auto-switch.

### Out of scope

- Per-model columns in `list`; the account list keeps the two-request summary path.
- Credits or reset-credit values.
- A persistent on-disk detail cache.

## Risks

- Full fetch adds a third request per account in live/`usage --all`; the TTL cache bounds it and normal `list` stays on the two-request path.
- A single model bucket at 0% may be more aggressive than the shared-window rule. The behavior is explicit and uses fresh data only.
- Partial summary/detail failures must keep usable data and a stable error code.

## Acceptance criteria

- [x] `usage --all` lists every stored account with lowest model headroom and reset.
- [x] `usage --all --json` returns account rows with `usage`, `buckets`, `lowest`, and `usage_error`.
- [x] `usage --all` rejects a query and handles no stored accounts.
- [x] Live auto-switch triggers on a fresh 0% model bucket even when the summary is healthy.
- [x] Stale model detail never triggers auto-switch.
- [x] The full cache follows the configured live interval.
- [x] `make verify` and `make verify-full` pass.
- [x] Real-account `usage --all` and `usage --all --json` work.
