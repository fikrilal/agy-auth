# Harness fixtures

These files are independent ground truth for external data shapes. They are not
generated by the implementation and must not contain real credentials.

- `credential.consumer.json` — full agy credential document with a fake ID token.
- `credential.minimal.json` — access-token-only document.
- `credential.invalid.json` — missing token object; must be rejected.
- `registry.valid.json` — valid registry index.
- `registry.invalid.json` — path-traversal account ID; must be rejected.

`harness contracts` validates these against the public parsers. Change a fixture
only when the external contract intentionally changes.
